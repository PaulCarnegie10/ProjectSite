# High-Level Idea
The high level idea of this project was to put my robotics and CS skills to work in order to create a drone, solder all the electronics, tune it, and have it flying autonomously and under manual control. That took me about a week and a half of locking myself in my room. The second part of this project is arguably much harder as it required setting up a jetson nano orin, setting up the unitree l2 lidar, and 3d modeling a whole mounting system to my drone. I got the jetson and lidar set up and am able to capture point clouds, and am currently working on the mounting system. I am using solidworks along with my 3d printer to rapidly prototype designs. Once I get the sensor package set up on the drone, I will map a park. End goal is to do localization via the terrain scanning (without GPS).
